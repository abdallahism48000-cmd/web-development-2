# Personal Budget Tracker

This project is a two-column responsive personal budget tracker built with HTML and CSS for the Week 2 assignment.

## Files

- `index.html` contains the page structure: the expense table, expense form, embedded budgeting video, logo, instructions section, and page headings.
- `style.css` provides the layout, responsive design, table borders and striping, form styling, hover/focus states, and the required advanced selectors.
- `assets/budget-logo.svg` is the local logo image displayed beside the main heading.

## Features

- A semantic expense table using `thead`, `tbody`, `tr`, `th`, and `td`, with five sample rows.
- An expense form with matching input IDs and a category dropdown containing Food, Transport, Rent, Entertainment, and Other.
- A local image with `src`, `alt`, and `width` attributes.
- A YouTube `iframe` with width, height, title, and frame border attributes.
- A native `details`/`summary` help section.
- Advanced CSS selectors, including descendant, direct-child, position, negation, and focus selectors.

The “Add Expense” button is intentionally inactive because JavaScript functionality is part of a later assignment.
